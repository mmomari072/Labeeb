# Labeeb v2.0.0 Roadmap Specification

## Purpose

v2.0.0 is the first release allowed to remove or change v1 APIs. It must provide a coherent Python-first contract for simulation campaigns, data transformations, execution, outputs, and optimization.

## Must-have scope

1. Database-aware derived attributes with row-index access, dependency validation, cycle detection, recomputation, units, and provenance.
2. Safe expression-aware assignment replacement for text templates.
3. Versioned case/result/output contracts and a migration guide.
4. Production execution lifecycle: cancellation, retries, timeouts, resume, and pluggable local/scheduler/container backends.
5. Reproducible OAT, correlated, bounded, and specialized sampling plus benchmarked sensitivity analysis.
6. First-class optimization integration with objectives, constraints, checkpoints, and optional AI backends.
7. Clean-install support, Python compatibility testing, API snapshots, executable case studies, and complete user/developer documentation.

## Explicitly deferred

CLI redesign, provider-specific online services, raw socket transports, and additional visualization polish are not v2 blockers unless they expose a public API contract required by the items above.

## Release gates

All must-have tasks are implemented, focused and full tests pass, clean-install and Python compatibility checks pass, independent QA approves the release, migration documentation is complete, and the annotated `v2.0.0` tag points to the verified release commit.
